# Mini-sumo-bot
Its a "little" sumo bot to see if my friend or I can make it better.
This sumo bot has 2 little motors and they are controlled using an L293D, and an Arduino uno R3(elgoo), as it's very DIY like I used a breadboard to connect everything and it worked, the way that it detects the other sumo bot is by using an ultrasonic sensor, the robot should spin until it detects that something is 50 cm away or less, the body of the bot was made using cardboard but I plan to make it look less DIY and more planned, maybe by using a 3D printed body, better motors, and a pcb...
